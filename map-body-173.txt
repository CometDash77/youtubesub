## Decisions so far
- [外观键定案：新增 6 个显示键（字体族 / 原文·译文字色与描边色 / 预览字号）与回退式兼容](https://github.com/CometDash77/youtubesub/issues/174) — 6 键全落 `display.*`（`font_family` / `orig_text_color` / `orig_stroke_color` / `trans_text_color` / `trans_stroke_color` / `preview_font_size`）；颜色存 RGB 三元素 int list（无 alpha）；字体名要新 `control` 种类 `font`（现码会把字符串整份丢掉、`stored_value` 返回 `None`）；六键全进 `TUNING_FIELDS`（插在 `bg_opacity` 之后，16→22 条）；不改 `default_settings()`（缺键即回退到今天硬编码值，老配置保存时不被顺手升级）。顺手勘误：译文默认色是 `#FFE082`，本图 Notes 与 [外观键定案](https://github.com/CometDash77/youtubesub/issues/174) 的前提原把它写作 `#FFE085`（均已于 2026-10-06 改正）。
- [共用绘制器定案](https://github.com/CometDash77/youtubesub/issues/175) — 接缝 = 新模块 `desktop/suboverlay/overlay_paint.py`（纯 `QtGui`/`QtCore`，不 import `QtWidgets`、不 import `settings`）+ 4 个无状态函数（`rows_for` / `paint_subtitles` / `draw_wrapped` / `draw_divider`）外加导出的 `content_area`；`OverlayWindow.paintEvent` 收成「取 rows → `paint_subtitles` → 状态行」。实测结论：`_draw_wrapped` / `_draw_divider` 本来就不读 `self`；折行 100% 由传入 `rect` 决定，**不需要 `max_width` 形参**；状态行是预览与真浮窗唯一被允许的差异（差异 1064 像素全在底部 24px 带内）；两条 render hint 与 `content_area` 必须归绘制器；`rows` 第三槽 `failed` 只给绘制器选色，失败态红仍是既有 `#FF5A5A` 契约；live style（合并未保存的控件值）即取即画、不改 `settings`。交给 [透明实时预览定案](https://github.com/CometDash77/youtubesub/issues/176)：折行逐字节相同只在 rect 相同时成立（内容区宽 622 → 4 行 / 772 → 3 行）→ 画布取 1:1 或离屏按真浮窗 rect 渲染再缩放。
- [透明实时预览定案：棋盘格画布、预览窗形态、活邻居文本与实时性能](https://github.com/CometDash77/youtubesub/issues/176) — 预览 = 「调参 → 显示」组顶部的一块画布 widget，调 #175 的 `paint_subtitles` 把**当前 cue 的行**按 live style 画进按 `(宽,高,DPR)` 缓存的 `QImage`，贴在一张**画布空间**的棋盘格 tile 上；不写 `settings`、不动浮窗、不画状态行。六条：①画布几何 = 1:1 优先、超宽才降级（`k = canvas_w / 图宽`，下限 0.5，触底退回 1:1 裁剪 + 拖动）；渲染范围 = 整窗 rect、不画状态行（画布高 = 浮窗高 − 24px 带，口径同 `desktop/tests/test_overlay_labels.py:217`）。②棋盘 = **固定贴图**（画布空间、逻辑像素定边长、物理边 `round(边长 × DPR)`，只在 DPR/画布尺寸变化时重建，**不随缩放重绘**）。③帧策略 = 每帧重跑 `rows_for` + `paint_subtitles` 写进按尺寸缓存的 `QImage`、**不限频**、不缓存布局；预览走带 path 的新信号（不触发页脚的 22 字段 `collect_edits()`）、只重绘画布块不整页重排。④浮窗本体**不跟变**（`desktop/suboverlay/debug_window.py:224-226` 不变，保存的原子写盘与取消的丢弃语义零冲突）。⑤只画**当前 cue** 的行（实测浮窗从来不显示上一句/下一句：`desktop/suboverlay/overlay.py:161-190` 只读当前 cue、`history` 只喂 `/status`（`desktop/app.py:180`）、`engine.tick()` 的 payload（`desktop/app.py:168-181`）无未来 cue）；回退示例文本须同时覆盖双语两行。⑥棋盘格 + 一个**默认关**、代码合成、**不进 `settings`** 的「垫一张示例画面」开关（#174 键表保持 6 键）。
