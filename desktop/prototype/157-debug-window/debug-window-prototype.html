说明 / 辅助

四态

同一套语义，在 A / B / C 里各用各的形态表达（状态块 / 状态胶囊 / 横贯状态带）。

正常
松绿填充 + 奶油字。用于「已连上、指标健康」。
进行中
芥末黄填充 + 靛蓝字。用于「正在跑、还没结论」。
错误
赭红填充 + 奶油字；正文级错误文字改用加深档 #8F3A29。
空
只有描边。用于「没有待办、没有记录」，不是错误。
磨砂两版配方
真 —— SetWindowCompositionAttribute(hwnd, ACCENT_ENABLE_BLURBEHIND=3, AccentFlags=2, GradientColor=0x00000000)：纯模糊、零 tint。浏览器里用 backdrop-filter 模拟。
伪 —— rgba(246,243,235,205) + 圆角 24 + 1px 内描边 rgba(255,255,255,110) + 48px 柔阴影，零系统 API 风险。

磨砂两版观感对照（实测真值）

这两张是「Win10 磨砂实现取证」票在本机实拍的原图，不是我画的 —— 左边是真磨砂（合成 API），右边是降级伪磨砂，同一张忙背景。

要看差别，背景必须忙。点底栏「背景：高对比 / 平淡」来回切就能看出来 —— 平淡背景上两版几乎一样，这也是取证票里的对照组结论。
浏览器里那版「真磨砂」是模拟，不是 Windows 合成器；真值只看这两张。
