# 调试窗口视觉原型（票 #157）

抛弃式稿子 —— 不是实现，不是交付物，看完就扔。

## 定案（2026-10-03，维护者裁定）

- **实施基准 = 变体 A「单列设置式」**。B / C 留作被否决的对照，**不要再从它们出发实现**。
- **2026-10-03 同日晚，维护者追加裁定：外层不做透明 / 磨砂。** 原话「保留内卡片就好了，外卡片的透明毛玻璃效果没有必要」。据此 A 的**磨砂开关作废** —— 外层窗口是**单版不透明**奶油底（`debug_tokens.WINDOW_RGBA=(246,243,235,255)`），内层卡片保留；`debug_frost` seam 已从代码里整条删除。本目录里的 `shot-A-真磨砂.png` / `ref-real-frost.png` / `ref-pseudo-frost.png` 与下面的磨砂实测对照**只作历史取证保留**，不再代表实施基准（现状权威见 `wayfinder/debug-window-style-tokens.md` §3）。
- A 的两页内容已换成决策票的真结论（本 session 按裁定改的）：
  - **调参页** = [调参页字段清单与保存 / 生效语义](https://github.com/CometDash77/youtubesub/issues/155) 的逐字段表 —— 显示外观 / 网络与服务（两颗「重启后生效」）/ 实验·未校准（整组带未校准标注）。凭证类字段一律不出现；底部只有「确定 / 取消」+ 一句「改完点「确定」才落盘一次」。
  - **排障页** = [排障页只读聚合口径](https://github.com/CometDash77/youtubesub/issues/156) 的 D1~D7 —— 顶部常驻状态条（松绿「已连接 127.0.0.1:<端口>」）+ 刷新档位（0.5s / 1s / 2s）+ 立即刷新 + 四分区（① 连接与帧 ② 播放与字幕 ③ 翻译队列 ④ 事件列表）+ 事件留痕（时间戳 / 相对秒数 / 明文）+ 复制全部；连通性测试报告默认折叠；页脚写明「只读页 —— 不改任何设置」。
- **B / C 的内容仍是密度占位**，没有按 #155 / #156 更新 —— 它们只用来比结构，不拿来比字段。

## 要回答什么

调试窗口到底长什么样：窗口骨架 / 调参页布局 / 排障页布局 / 磨砂两版观感 / 状态色。

## 三套变体

| | 骨架 | 调参页 | 排障页 | 底部动作区 |
|---|---|---|---|---|
| **A 单列设置式**（定案） 560×672 | 标题行 + segmented 两页切换 | 单列滚动分组，左标签右控件，说明与范围贴控件旁 | 状态条 + 四分区 + 事件留痕（按 #156） | 调参页「取消 / 确定」；排障页换「只读页 —— 不改任何设置」 |
| **B 开发者控制台**（被否决） 900×624 | 左栏 184px 导航（分组 / 分区） | 主从式：选一组，右侧只显示该组控件 | 顶部四枚状态胶囊 + 左右分栏（指标表 / 事件流），另有总览 / 事件流 / 环境信息三个子视图 | 细工具条 +「保存到配置」 |
| **C 仪表盘卡片流**（被否决） 744×600 | 大标题 + 居中 pill tab | 分组卡片 2 列网格，卡内校验 banner | 横贯状态带 + 2×2 卡片网格（含空态虚线卡） | 右下角主次按钮，无分隔线 |

三套在结构上互相不兼容（不是换色）：导航位置、信息层级、主操作都不同。

## 两处必须说清

1. **B / C 的页面内容是密度占位，不是字段清单**；A 才是按 #155 / #156 填过的。
2. **浏览器里的「真磨砂」是 `backdrop-filter` 模拟**，不是 Windows 合成器。真值看 `shot-磨砂实测对照.png`（#154 的实测原图）。
